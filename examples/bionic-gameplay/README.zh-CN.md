# 仿生玩法扩展示例

将 `datapack/` 放入世界的 `datapacks/` 并执行 `/reload`。需要网络协议 44 的新版 Create Biotech。

这个数据包会实际改变玩法，所有条目都可独立删除：

- 狼组织增加捕猎苦力怕的关系；牛组织增加威慑僵尸及向铁傀儡呼救的关系。
- 产蛋改为每个产蛋器官掉落 1–2 个金粒。
- 驴货箱使用木桶安装，容量 27；猪使用皮革安装双人鞍座；狼组织改用面包驯服，概率 70%。
- `example:gland` 要求同一捕获来源的头与角，周期使用战利品表分泌史莱姆球，并允许玻璃瓶采集蜂蜜瓶。
- 僵尸头提供 `example:ice_caster`，使用统一调度器发射两颗雪球。雪球沿用原生雪球的伤害规则。
- `example:armor_echo` 自动读取供体基础护甲的 50%，通过已有属性组件增加成品护甲。

可另外安装 `kubejs/server_scripts/bionic_gameplay.js`，演示声明规则、修改产物、取消水下施法和调整驯服概率。该脚本的产出与攻击回调依赖本示例数据包；单独安装时，只有金粒产蛋和驯服事件有对应效果。

移除资源并 `/reload` 会撤销定义和规则。已有掉落保留，货箱容量缩小时溢出物品会掉落。

完整字段、Java API、事件时机与验证边界见 [玩法扩展说明](../../docs/bionic-gameplay-extension.zh-CN.md)。
