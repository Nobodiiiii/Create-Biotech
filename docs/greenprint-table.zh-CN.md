# 绿图桌

创造物品栏中，绿图桌位于绿图旁边。打开桌子，在左槽放一张空白绿图，选择本地 `.nbt` 文件，点击「导入」，从右槽取出成品。用成品右键有足够空间的地面即可释放拟态。

「打开文件夹」会打开当前 Minecraft 实例下的 `greenprints/`。把绿图 `.nbt` 放入该目录后，点击「刷新」。把已绑定的绿图放入左槽，点击「导出」可在该目录保存副本。多人游戏读取玩家本机的文件，服务端接收文件内容并负责写入物品。导入整只实体的快照需要创造模式。

## 文件结构

`.nbt` 是 GZIP 压缩的 Minecraft NBT。根复合标签的 `MimicEntity` 对应物品组件 `minecraft:custom_data` 里的同名标签。它包含实体 ID、拟态状态以及实体保存的装备等数据。仿生拟态的 `SurgicalAssembly` 保存供体模板、保留的体块、位移、旋转、连接、关节与测量结果。导入沿用实体加载与手术存档迁移，写回成品时使用当前格式。
