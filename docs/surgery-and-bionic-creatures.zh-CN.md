# 手术台与仿生生物玩家指南

[English](surgery-and-bionic-creatures.md) · [中文](surgery-and-bionic-creatures.zh-CN.md)

这是一个未完成的功能，在未来的正式版中会有不兼容旧版本的修改，因此**不建议**在你的长期生存档中进行游玩。这是一个较大的系统，思索尚未完成，具体玩法可以阅读本指南。

你可以使用手术台用于拆解和重组史莱姆拟态生物。部件可以重新摆放，也可以和其他生物的部件混用；装上关节后，头、手臂和腿就能活动。完成后装箱并放出，即可得到仿生生物“史莱姆？”。

成品的表现取决于保留的部件、组装方式和关节位置，部分供体拥有独特的性质（未完成）。

该部分可能与客户端单独修改模型的模组产生冲突。

## 快速开始

1. 用**史莱姆培养皿**培养拟态生物，具体参考史莱姆培养皿的思索。
2. 把拟态生物装进纸箱。
3. 铺设手术台。水平相邻且高度相同的手术台会连成一整块工作面，复杂身体需要较大的台面。
4. 将装有拟态生物的纸箱放在桌面上，转化为部件，此过程不可逆。
5. 切分、摆放并粘合需要的部件，再安装活动关节。
6. 用空纸箱收起完整身体，按住 `Alt` 检查属性，潜行右击释放成品。
7. 已经完成的“史莱姆？”也能放回手术台继续改装。

## 基本操作

- 手持手术盒时，长按手术盒快捷键（默认 `Alt`），把光标移到所需工具上，松开按键完成切换。
- 手术盒里的工具只在手术台上生效；对应的独立工具或材料也可以直接使用。
- 准星命中部件、接缝、关节或台面后，屏幕会显示当前可执行动作和所需按键。
- 给相连工作面中的任意一张手术台通入红石，可以暂时显示各部件原本的生物外观，便于辨认来源；这不会改变组装结果。

## 工具总览

> 工具的具体按键、选择顺序和当前步骤，请以准星命中目标时的屏幕提示为准。下面只说明各工具的总体用途。

| 工具 | 总体功能                                                        |
| --- |-------------------------------------------------------------|
| 剪刀 | 剪开生物原有接缝或后加的粘合连接，也可解除或整体取下已固化的组合。                           |
| 铲子 | 丢弃命中的完整连通部件并回收一些黏液球；也可清理与某块台面相交的全部部件。      |
| 强力胶 / 智能强力胶 | 把两个部件的选中位置粘在一起。智能强力胶还能在确认前微调位置和倾角。                          |
| 蜂蜜瓶 | 把命中的整个连通部分固化成一个刚性组合，适合先做成躯干、手臂或腿段。在剪切和计算关节时，该组合会被视为一个完整的部件。 |
| 黏液球 | 给两个已经实际贴合、但逻辑上尚未直接相连的方块补一条胶缝。                               |
| 对称之杖 | 参照已有粘合关系和所选中心面，把另一个现成部件对称放置并粘合；它不会凭空复制新部件。                  |
| 扳手 | 拆下命中的活动关节并回收关节物品。                                           |
| 临时纸箱 | 暂时收起一个完整连通部分，用于换位或搬到另一块手术台。                                 |
| 空纸箱 | 把命中的完整连通部分包装成品。未连接的零件会留在台面上。                                |

通常情况下，剪切、粘合和蜂蜜固化不消耗材料或手术盒耐久；服主可以调整这一规则。安装关节会消耗关节物品，拆下后可以回收。

可以安装关节来使部件活动。关节决定哪些部件会被识别为头、手臂或腿，并获得相应的功能和动画。

| 关节 | 作用与限制                   |
| --- |-------------------------|
| 颈关节 | 让头部随身体朝向转动；一具身体最多安装一个。  |
| 肩关节 | 把活动部件识别为手臂，使其参与挥击；最多八个。 |
| 肘关节 | 让前臂随上臂弯曲；能且只能依附唯一的肩关节。  |
| 髋关节 | 把活动部件识别为腿，使其参与步态；最多八个。  |
| 膝关节 | 让小腿随步态屈伸，能且只能依附唯一的髋关节。  |

一级关节（颈、肩、髋）不能串接在另一个一级关节下面；一个活动部件也不能同时由多个关节驱动。关节只能安装在直接相连、但未被蜂蜜固化为同一组合的两部分之间。

关节会根据实际形态自动调整动画。

## 成品属性怎样决定

生命上限按最终模型的非重叠体积计算，体型越大，额外体积的收益越低。移动与攻击由最终形状和有效关节决定；供体属性不会继承。

身体碰撞核心的水平位置和宽度也按去除重叠后的体积分布计算，堆叠相同体块或加入被完全包住的体块不会增加该处权重。手臂不参与碰撞核心计算，身体高度保留非手臂体块的完整跨度；薄片仍按最小厚度参与碰撞权重。碰撞核心与生命体积测量共用体块几何预处理，并在计算范围及厚度规则一致时复用并集采样。

### 查看属性

在 JEI 中，对供体预览图标、刷怪蛋或装有生物的大小纸箱按配方键或用途键，都可以反查该物种提供的仿生特性。刷怪蛋按实际生成类型、纸箱按捕获类型查询，空箱和无效捕获类型不参与反查。三种入口共用服务端供体索引，JEI 启动后自动分批加载，数据包重载后自动更新；刚进入世界时若索引尚未加载完，可稍后重新查询。反查展示物种级供体能力，不按箱内个体状态或成品装配筛选。客户端配置 `showBionicTraitDonorsInJei` 同时控制供体列表、反查和索引同步。

把仿生生物装进纸箱后，按住 `Alt` 展开“基础数值”。其中会显示生命上限、伤害（DPS）、移动速度、护甲、击退相关属性，以及有效的头、手臂和腿数量。这里的 DPS 以全部手臂可用的固定协调参数为基准，不计智力、武器、附魔、状态效果和具体目标位置。

腿部是否接地、腿长、是否有膝盖、腿部占整个身体的比例都会影响移动速度。攻击距离取决于肩部到手端的静态臂长，体积和粗细决定基础伤害与节奏，能够参与当前攻击的手臂数量提供有限的频率收益。

获得飞行能力后，有效翅膀或悬浮组织占全身保留组织的体积比例越大，飞行越快，额外占比的收益逐渐减小。扑翼飞行仍需先满足有效翼数量和承重条件；悬浮飞行仍需满足躯干覆盖率条件。自主飞行和骑乘共用飞行速度、加速与减速规则；普通寻路和持续满速骑乘的稳定速度一致。跟随主人的寻路倍率可以提高自主飞行速度，飞行不额外叠加骆驼疾跑速度。

### 近战方向与频率

生物需要先转向目标，再从可用手臂中选择合适的一只攻击。攻击区域从肩部出发，由肩到肘（无肘时为肩到手端）的大臂装配方向固定决定，目标位置不会改变扇区。纵向总张角不超过 90°：水平大臂上下各 45°，垂直下垂大臂覆盖水平面到正下方，不能攻击肩部水平面以上，中间角度连续线性插值。该区域再与真实臂长、手臂装配活动范围取交集，水平方向仍钳制在身体正前方 180° 内。准备结束后方向锁定，绕到范围外或退出攻击距离可以躲开这一击。没有手臂几何的身体使用最远 1.5 格的短距离身体攻击。

装配姿态会产生分工：下垂、平伸、上举手臂的最终纵向扇区分别为 0°–90°、−45°–45°、−90°–0°，斜向姿态在这些端点间连续插值；侧伸手臂的水平扇区固定偏向本侧，但偏置强度同时乘以大臂的水平分量，因此近乎竖直的普通手臂不会因轻微外倾而丢失正前方。选臂会考虑这些差异，攻击间隔和恢复时间不增加姿态修正。新打包的生物保存装配朝向，缺少此数据的旧生物使用朝向正前方的通用固定范围。

无肘和有肘手臂使用相同的动作总时长，标准均为 20 tick，从起手一直覆盖到动画完全复位。无肘按独立短准备位置后移 2 tick；有肘以实际空手或武器动画的命中关键帧为基础，四舍五入后前移 4 tick。三者的接触窗口均为 5 tick，同一击最多尝试造成一次伤害。手臂分别恢复，同时全身两次出手至少相隔 12 tick（0.6 秒）；可用手臂较多时，全局间隔最多缩短 20%。落空和被盾牌挡住也要恢复，切换目标不会刷新冷却。

智力按简单、普通、高级分类，多头取已识别头部中的最高智力，无可识别头部时使用普通智力。村民（`AbstractVillager`）、猪灵（`AbstractPiglin`）、袭击生物（`Raider`）及其模组子类自动识别为高级，其余默认普通；简单智力只通过数据包指定。原版的普通／简单覆盖保留在 `bionic_head/intelligence/defaults.json`，其中劫掠兽覆盖为普通，悦灵也按普通处理。性情和智力统一属于头部属性，在属性列表中最先显示。供体原始头部至少保留一半体积并安装在头部时才贡献这两项属性。简单智力只使用计入该手所持武器伤害后的单臂 DPS 最高的手臂，不计武器攻速、附魔和状态效果，实际出手间隔仍由手臂与协调参数决定；相同 DPS 固定取右侧槽位、左侧槽位顺序中的第一只，该臂冷却中或打不到目标时也不会换臂，不享受其他手臂的协调加速。普通智力保持按姿态、武器和轮换选臂，攻击期间停步。高级智力按同样方式选臂，但攻击期间会继续追击，接触阶段的攻击方向仍然锁定。所有分类都使用 1.0 的恢复系数、10°/tick 的转身上限和 12°/tick 的准备期瞄准修正；单只标准僵尸手臂的间隔统一为 20 tick。

命中与冷却由服务端规则决定；有肘动作的服务端出伤位置以动画命中关键帧的整数换算为基准并应用时机偏移，无肘动作保留独立准备位置。动画手部轨迹不会改变攻击范围。实现参数与验证方式见[近战机制说明](bionic-melee-combat.zh-CN.md)。
