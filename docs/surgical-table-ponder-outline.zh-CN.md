# 手术台思索大纲

主题：组装你的第一只仿生生物。

演示案例：给僵尸拟态生物换上铁傀儡手臂。

共分为五个大场景，每个大场景内按顺序安排具体步骤。“文本”为对应步骤的思索字幕。

## 大场景一：认识手术台与放置供体

目标：让玩家知道手术台的用途，并完成放置。

1. **展示成品**

   画面：仿生生物走入画面，转头并挥动替换后的手臂。

   文本：“使用手术台，可以拆解拟态生物，并将不同来源的部件组装成新的拟态生物。”
2. **铺设工作面**

   画面：手术台逐块出现，连接成一整块台面。

   文本：“相邻的手术台会连接成一整块工作面。”
3. **准备供体**

   画面：展示培养皿生长动画，出来一个拟态僵尸。

   文本：“先使用史莱姆培养皿培养拟态生物，查看它的思索来了解更多。”
4. **放置主体**

   画面：捕捉该僵尸，然后右击后平放在台面上。

   文本：“使用捕捉网或纸箱来捕捉拟态生物，右击台面即可放置。”
5. **说明转化并放置供体**

   画面：高亮主体的各个体块，再在旁边放置铁傀儡拟态生物。

   文本：“放上手术台后，拟态生物会转化为手术部件，这个过程不可逆。”
6. 画面：放置一个拉杆并充能。

   文本：“对相连台面的任意位置充能，可以使手术台显示生物原本外观”

## 大场景二：切分与搬动部件

目标：拆下原手臂，取得替换用的供体手臂。

1. **切换工具**

   画面：展示手术盒轮盘，选中剪刀。

   文本：“手持手术盒，长按工具切换键，移向所需工具后松开。默认按键为 Alt。”
2. **剪下原手臂**

   画面：高亮僵尸的肩部连接，用剪刀将手臂分离。

   文本：“使用剪刀右击连接处，可以将相连的部件切开。”
3. **搬动部件**

   画面：使用临时纸箱拾起旧手臂，放到台面边缘。

   文本：“使用临时纸箱，可以拾起并重新摆放整个连通部分。”
4. **取得替换手臂**

   画面：剪下铁傀儡的一只手臂，将它移到僵尸躯干旁。

   文本：“从其他供体上取下需要的部件，就可以用它替换原来的身体结构。”

## 大场景三：调整、组合与粘合

目标：理解部件如何定位，以及粘合与蜂蜜组合的区别。

1. **调整位置与角度**

   画面：用扳手选中新手臂，演示平移、旋转和确认。

   文本：“使用扳手可以预览调整部件的位置和角度。右击确认，左键取消。”
2. **演示蜂蜜组合**

   画面：在台面空处展示几个相连体块，用蜂蜜瓶固化后整体搬动。

   文本：“蜂蜜瓶可以把整个连通部分固化成一个刚性组合，适合制作躯干或肢体段。”
3. **保留活动边界**

   画面：分别高亮躯干与手臂，标出两者之间将要安装关节的位置。

   文本：“需要通过关节活动的两部分，应保持独立，不要用蜂蜜将它们固化为同一个组合。”
4. **粘合替换手臂**

   画面：用强力胶依次选择手臂和躯干上的粘合位置，展示对齐并确认。

   文本：“使用强力胶依次选择两个粘合位置，将新部件连接到身体上。确认时，两个部件必须实际接触。”

## 大场景四：安装活动关节

目标：让组装完成的身体能够转头、挥击和行走。

1. **安装肩关节**

   画面：选择肩关节，先右击替换手臂，再右击躯干。

   文本：“安装关节时，先选择活动部件，再选择它绕之旋转的部件。肩关节会将活动部分识别为手臂。”
2. **安装其他关节**

   画面：依次为另一只手臂、头部和两条腿安装关节，标出对应名称。

   文本：“颈关节让头部转动，肩关节让手臂挥击，髋关节让腿部参与行走。”
3. **强调安装条件**

   画面：特写两个直接相连的独立部件，在连接处高亮关节。

   文本：“关节只能安装在直接相连、但未被蜂蜜固化为同一组合的两部分之间。”

## 大场景五：装箱、检查与释放

目标：完成制作，并展示检查和继续改装的入口。

1. **装箱收起**

   画面：用空纸箱收起完整身体，旧手臂和供体剩余部件留在台面上。

   文本：“使用空纸箱，可以收起命中的整个连通部分。未连接的零件会留在台面上。”
2. **查看属性**

   画面：展示成品纸箱，展开属性提示，强调基础数值与特性区域。

   文本：“装箱后，按住 Alt 可以检查基础数值、仿生特性，以及尚未满足的特性条件。”
3. **释放成品**

   画面：潜行右击释放成品，依次展示行走、转头和挥击。

   文本：“潜行右击放出成品。身体结构、有效关节和保留的供体组织，将共同决定它的表现。”
4. **继续改装**

   画面：将成品重新装箱并放回手术台，最后展示几种不同的组装结果。

   文本：“完成的仿生生物也能放回手术台继续改装。尝试不同的部件与组合，创造你自己的身体结构。”
