# 手术台思索大纲

主题：组装你的第一只仿生生物

演示案例：给僵尸拟态生物换上铁傀儡手臂

共分为五章，依次为“放置供体”“切分与重组”“安装关节”“特性介绍”“全工具介绍”。前三章保留画面安排，后两章仅追加文本。每章内按顺序安排具体步骤，“文本”为对应步骤的思索字幕；同一步中有多条文本时依次显示。

前三个大场景沿用同一套台面和部件布局，后续场景从上一场景的完成状态继续。第四章以苦力怕和幻翼组成轰炸机为例介绍仿生特性，第五章介绍全部手术工具。

## 大场景一：放置供体

目标：让玩家知道手术台的用途，并完成放置

1. **展示成品**

   画面：仿生生物走入画面，转头并挥动替换后的手臂

   文本：“使用手术台，可以拆解拟态生物，并将不同来源的部件组装成新的拟态生物”

2. **铺设工作面**

   画面：手术台逐块出现，连接成一整块台面

   文本：“相邻的手术台会连接成一整块工作面”

3. **准备供体**

   画面：展示史莱姆培养皿的生长动画，随后生成一只僵尸拟态生物

   文本：“先使用史莱姆培养皿培养拟态生物，查看它的思索来了解更多”

4. **放置主体**

   画面：使用捕捉网捕捉刚生成的僵尸拟态生物，再右击台面，将它平放在手术台上；同时展示纸箱作为另一种捕捉工具

   文本：“使用捕捉网或纸箱来捕捉拟态生物，右击台面即可放置”

5. **说明转化**

   画面：高亮主体的各个体块

   文本：“放上手术台后，拟态生物会转化为手术部件，这个过程不可逆”

6. **放置其他供体**

   画面：在同一工作面的另一侧放置铁傀儡拟态生物，与僵尸保持足够的操作间距

   文本：“同一台面上可以放置多个拟态生物”

7. **查看供体原本外观**

   画面：放置一个能为台面提供红石信号的拉杆，打开后展示供体原本外观，再关闭拉杆恢复手术显示

   文本：“对相连台面的任意位置充能，可以使手术台显示生物原本外观”

## 大场景二：切分与重组

目标：拆下原手臂，取得供体手臂并完成替换

1. **切换工具**

   画面：展示手术盒轮盘，选中剪刀

   文本：“使用工具可以拆解并重组台面上的生物”

2. **剪下原手臂**

   画面：高亮僵尸的肩部连接，用剪刀将手臂分离

   文本：“使用剪刀右击连接处，可以将生物以体块为单位切开”

3. **搬动部件**

   画面：使用临时纸箱拾起旧手臂，放到台面边缘

   文本：“使用纸箱，可以拾起并重新摆放整个连通部分”

4. **替换并粘合手臂**

   画面：剪下铁傀儡的一只手臂；使用强力胶先选择手臂上的粘合位置，再选择僵尸躯干上的对应位置，展示移动、贴合与确认的过程

   文本：“从其他供体上取下需要的部件，使用强力胶依次选择两个粘合位置，就可以用它替换原来的身体结构”


5. **介绍手术盒**

   画面：展示一个手术盒掉落物，用指向它的交互提示强调工具切换功能，并短暂展示轮盘

   文本：“手术台还支持许多其他工具，合成一个手术盒以快捷切换”

   右上角补充文本：“更多工具的功能将会在后续章节介绍。”

## 大场景三：安装关节

目标：让组装完成的身体能够转头、挥击和行走

1. **展示未安装关节的成品**

   画面：用纸箱收起刚才组装完成的身体，在台面旁放出，展示没有活动关节时的跳跃与接触攻击

   文本：“到现在为止，组装后的生物只会像史莱姆一样跳跃和撞击”

2. **引出活动关节**

   画面：重新捕捉成品并放回台面，依次高亮头部、手臂和腿部

   文本：“你需要安装关节来让它获得转头、挥击和行走的能力”

3. **认识关节类型**

   画面：展示关节掉落物和类型选择轮盘，按头部、手臂、腿部的顺序强调各类关节

   文本：“颈关节对应头部，肩关节和肘关节对应大小臂，髋关节和膝关节对应大小腿”


4. **安装活动关节**

   画面：先为替换后的手臂安装肩关节，明确展示“先点手臂、再点躯干”的顺序；随后依次为另一只手臂、头部和两条腿安装肩关节、颈关节和髋关节

   文本：“先右键活动体块（如大臂），再右键固定体块（如身体），即可安装关节”

5. **强调安装条件**

   画面：特写两个直接相连的独立部件，在连接处高亮关节

   文本：“关节只能安装在直接相连的两体块之间”

6. **展示安装效果**

   画面：将安装好关节的成品装箱并放出，依次展示转头、手臂挥击和双腿行走，与本章开头的跳跃动作形成对比


7. **说明基础属性**

   画面：依次高亮全身、替换后的手臂和腿部，配合生命、伤害和移速图标；最后将成品装箱，展示按住 Alt 查看基础数值的提示

   文本一：“成品拟态生物的基础属性会随对应部位的体积等因素改变”

   文本二：“如整体体积越大，生命值越高；手臂体积越大，伤害越高；腿部长度越长，移速越快”


## 第四章：特性介绍

目标：以苦力怕和幻翼组成轰炸机为例，让玩家理解特性的来源、生效条件与检查方法

1. **认识仿生特性**

   文本一：“除了改变外形和基础数值，保留的供体组织还能赋予成品独特的仿生特性”

   文本二：“例如，把苦力怕的自爆与幻翼的扑翼飞行组合起来，就能制作一架会飞的生物轰炸机”

2. **查找特性与供体**

   文本一：“在 JEI 中查看手术指南的用途，可以查阅各项特性的效果、生效条件和供体”

   文本二：“对供体预览图标、刷怪蛋或装有生物的纸箱查看配方或用途，也能反查这个物种提供的特性”

3. **准备轰炸机的主体**

   文本一：“先准备苦力怕与幻翼拟态生物，以苦力怕的身体作为主体，取下幻翼的两侧翅膀备用”

   文本二：“自爆是一项躯干特性。默认规则下，苦力怕组织至少要占躯干组织体积的一半，才能使它生效”

4. **安装幻翼翅膀**

   文本一：“保留每侧翅膀的翼根和翼尖，先将同一侧相连的翼部体块用蜂蜜固化成一段，再分别粘到主体两侧”

   文本二：“为每侧翅膀安装肩关节：先选择翅膀，再选择躯干，让它们被识别为两条独立的活动肢体”

   文本三：“翅膀与躯干之间要保留活动边界，不要将它们用蜂蜜固化成同一个组合”

5. **满足飞行条件**

   文本一：“默认需要至少两条有效翼；每条翼所在的手臂中，翅膀组织的体积占比都要达到一半”

   文本二：“翅膀还要能承受身体重量：默认身体体积不能超过有效翼组织总体积的十六倍”

   文本三：“如果承重不足，可以减少多余身体组织，或增加有效翼组织，再次检查特性是否生效”

6. **检查特性是否生效**

   文本一：“将成品装进纸箱，按住 Alt 查看特性列表，确认自爆与扑翼飞行都已生效”

   文本二：“灰色特性表示条件尚未满足。按提示检查组织占比、安装部位、关节和配套组织，再放回手术台调整”

7. **理解轰炸机的行为**

   文本一：“同时获得这两项特性后，成品就能通过振翅飞行，并用自身爆炸攻击敌人”

   文本二：“没有主人的成品接近敌人时会膨胀自爆；有主人时，只会由主人使用打火石或火焰弹点燃引爆”

8. **尝试更多特性组合**

   文本一：“不同特性对组织来源、占比和安装位置的要求不同，部分还需要对应关节或配套器官”

   文本二：“参考 JEI 中的条件说明，保留需要的组织，尝试制作适合不同用途的仿生生物”

## 第五章：全工具介绍

目标：介绍手术盒内全部工具，以及关节、成品纸箱和创造手术盒的用途与操作

1. **切换工具与查看提示**

   文本一：“手持手术盒，长按工具切换键，将光标移向所需工具后松开。默认按键为 Alt”

   文本二：“普通手术盒提供剪刀、铲子、智能强力胶、蜂蜜瓶、黏液球、对称之杖、扳手和临时纸箱”

   文本三：“这些工具在手术台上使用；对应的独立工具或材料也可以直接使用。具体操作以准星命中目标时的屏幕提示为准”

2. **剪刀：剪开连接与拆卸关节**

   文本一：“用剪刀右击原有接缝或后加的胶缝，可以剪开该处连接；出现摆放预览时，再次右击确认位置，左键取消”

   文本二：“按住 Ctrl 右击，可以一次剪开命中部件的全部直接连接”

   文本三：“对蜂蜜固化的组合右击可以解除组合；按住 Ctrl 右击则将它作为整体取下”

   文本四：“直接命中活动关节时，剪刀会优先拆下关节，并回收关节物品”

3. **铲子：清理多余部件**

   文本一：“用铲子右击部件，会铲除命中的整个连通部分，并回收一些黏液球”

   文本二：“按住 Ctrl 右击某块台面，可以清理与这块台面相交的所有部件；铲除前请确认高亮范围”

4. **强力胶：连接两个部件**

   文本一：“先右击待移动部件上的粘合位置，再右击目标位置，强力胶会将两个部件对齐并连接”

   文本二：“粘合位置必须实际接触，且台面要有足够空间容纳组装后的部件”

5. **智能强力胶：微调后粘合**

   文本一：“手术盒使用智能强力胶。选好两个粘合位置后，可以先微调预览，再右击确认；左键取消”

   文本二：“瞄准不同面选择调整轴，滚轮每次平移三十二分之一格，Ctrl 加滚轮每次旋转五度”

   文本三：“累计平移最多四格；确认时检查接触与空间，未通过时可以继续调整”

6. **蜂蜜瓶：固化刚性组合**

   文本一：“用蜂蜜瓶右击，可以将命中的整个连通部分固化为一个刚性组合，适合先制作躯干或一段肢体”

   文本二：“组合在剪切与安装关节时会被视为一个完整部件。需要相对活动的两部分，应分别固化”

7. **黏液球：补上原位胶缝**

   文本一：“两个体块已经实际贴合，却没有直接连接时，用黏液球依次右击它们，可以补上一条胶缝”

   文本二：“补缝会保留两个体块当前的位置，适合连接已经摆好的部件”

8. **对称之杖：对称摆放现有部件**

   文本一：“先选待对称粘合的部件，再选已经粘好的参考部件，最后选择中心对称面”

   文本二：“工具会参照已有粘合关系，对称复现位置与倾角，将准备好的部件粘到另一侧”

   文本三：“默认从蜂蜜组合选择中心面；按住 Ctrl 右击，可以改从参考连接中的被粘合体块选择中心面”

   文本四：“操作前要准备好另一份部件，对称之杖不会凭空复制部件”

9. **扳手：调整位置与姿态**

   文本一：“用扳手右击体块，开始单体调整；按住 Ctrl 右击，以命中体块为中心调整整个连通部分”

   文本二：“瞄准不同面选择调整轴，滚轮平移，Ctrl 加滚轮旋转；步长与智能强力胶相同，累计平移最多四格”

   文本三：“再次右击校验并提交，左键取消全部预览改动。确认失败时，可以继续调整”

   文本四：“按住 Shift 右击，可以将整个连通部分以最小角度摆正并重新落地，直接完成调整”

   文本五：“单体调整至少要保留一处原有连接，不再接触的普通连接会在确认后断开；关节连接必须保留，拆卸关节请用剪刀”

10. **临时纸箱：搬动连通部分**

    文本一：“手术盒中的临时纸箱用于搬动完整连通部分，右击选中后，再对台面右击完成重新摆放”

    文本二：“选中前按住 Ctrl 可以预览落地面；摆放时按住 Ctrl 加滚轮切换六个落地面朝向，再用 Ctrl 加右击按所选朝向放置”

11. **关节：指定活动部位**

    文本一：“关节需要另外准备。手持关节，长按工具切换键打开类型轮盘，选择后松开”

    文本二：“颈关节对应头部，肩关节和肘关节对应上臂与前臂，髋关节和膝关节对应大腿与小腿”

    文本三：“先右击活动部件，再右击固定部件。两者要直接相连，且不能被蜂蜜固化在同一组合内”

    文本四：“颈、肩、髋关节不能上下串联；肘关节必须依附唯一的肩关节，膝关节必须依附唯一的髋关节，每个肩或髋最多连接一个对应的二级关节”

12. **空纸箱：装箱与释放成品**

    文本一：“使用另外准备的空纸箱，可以把命中的整个连通部分包装为成品；未连接的部件会留在台面上”

    文本二：“按住 Alt 检查基础数值和特性，潜行右击释放成品。成品也能重新放回手术台继续改装”

13. **材料与耐久**

    文本一：“默认情况下，剪切、粘合和蜂蜜固化不消耗材料或手术盒耐久，服务器可以调整这项规则”

    文本二：“安装关节会消耗关节物品，拆下后可以回收”

14. **创造手术盒：额外的四种工具**

    文本一：“创造手术盒提供另一组工具，同样通过长按工具切换键选择”

    文本二：“拟态转化器：右击普通生物，将它变为拟态生物；拟态复原剂：右击拟态生物，使它恢复正常”

    文本三：“拟态附身器：右击缠魂后的生物可以附身或切换身体，附身后潜行右击可以脱离”

    文本四：“部件复制工具：首次右击复制命中的整个连通部分，再次右击台面按预览放置副本，原部件保留”
