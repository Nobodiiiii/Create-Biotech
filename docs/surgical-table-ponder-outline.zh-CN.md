# 手术台思索大纲

主题：组装你的第一只仿生生物

演示案例：前三章给僵尸拟态生物换上铁傀儡手臂，第四章以苦力怕和幻翼组成轰炸机为例介绍特性

共分为五章，依次为“放置供体”“切分与重组”“安装关节”“特性介绍”“全工具介绍”。每章内按顺序安排具体步骤，“画面”为配合字幕的演示描述，“文本”为对应步骤的思索字幕；同一步中有多条文本时依次显示。

前三个大场景沿用同一套台面和部件布局，后续场景从上一场景的完成状态继续。第四章用轰炸机的组织与装配说明仿生特性的通用逻辑，第五章用台面上的独立部件展示各工具的用途。以下内容均为文字大纲。

## 大场景一：放置供体

目标：让玩家知道手术台的用途，并完成放置

1. **展示成品**

   画面：仿生生物走入画面，转头并挥动替换后的手臂

   文本：“使用手术台，可以拆解拟态生物，并将不同来源的部件组装成新的拟态生物”

2. **铺设工作面**

   画面：手术台逐块出现，连接成一整块台面

   文本：“相邻的手术台会连接成一整块工作面”

3. **准备供体**

   画面：展示史莱姆培养皿的生长动画，随后生成一只僵尸拟态生物

   文本：“先使用史莱姆培养皿培养拟态生物，查看它的思索来了解更多”

4. **放置主体**

   画面：使用捕捉网捕捉刚生成的僵尸拟态生物，再右击台面，将它平放在手术台上；同时展示纸箱作为另一种捕捉工具

   文本：“使用捕捉网或纸箱来捕捉拟态生物，右击台面即可放置”

5. **说明转化**

   画面：高亮主体的各个体块

   文本：“放上手术台后，拟态生物会转化为手术部件，这个过程不可逆”

6. **放置其他供体**

   画面：在同一工作面的另一侧放置铁傀儡拟态生物，与僵尸保持足够的操作间距

   文本：“同一台面上可以放置多个拟态生物”

7. **查看供体原本外观**

   画面：放置一个能为台面提供红石信号的拉杆，打开后展示供体原本外观，再关闭拉杆恢复手术显示

   文本：“对相连台面的任意位置充能，可以使手术台显示生物原本外观”

## 大场景二：切分与重组

目标：拆下原手臂，取得供体手臂并完成替换

1. **切换工具**

   画面：展示手术盒轮盘，选中剪刀

   文本：“使用工具可以拆解并重组台面上的生物”

2. **剪下原手臂**

   画面：高亮僵尸的肩部连接，用剪刀将手臂分离

   文本：“使用剪刀右击连接处，可以将生物以体块为单位切开”

3. **搬动部件**

   画面：使用临时纸箱拾起旧手臂，放到台面边缘

   文本：“使用纸箱，可以拾起并重新摆放整个连通部分”

4. **替换并粘合手臂**

   画面：剪下铁傀儡的一只手臂；使用强力胶先选择手臂上的粘合位置，再选择僵尸躯干上的对应位置，展示移动、贴合与确认的过程

   文本：“从其他供体上取下需要的部件，使用强力胶依次选择两个粘合位置，就可以用它替换原来的身体结构”


5. **介绍手术盒**

   画面：展示一个手术盒掉落物，用指向它的交互提示强调工具切换功能，并短暂展示轮盘

   文本：“手术台还支持许多其他工具，合成一个手术盒以快捷切换”

   右上角补充文本：“更多工具的功能将会在后续章节介绍。”

## 大场景三：安装关节

目标：让组装完成的身体能够转头、挥击和行走

1. **展示未安装关节的成品**

   画面：用纸箱收起刚才组装完成的身体，在台面旁放出，展示没有活动关节时的跳跃与接触攻击

   文本：“到现在为止，组装后的生物只会像史莱姆一样跳跃和撞击”

2. **引出活动关节**

   画面：重新捕捉成品并放回台面，依次高亮头部、手臂和腿部

   文本：“你需要安装关节来让它获得转头、挥击和行走的能力”

3. **认识关节类型**

   画面：展示关节掉落物和类型选择轮盘，按头部、手臂、腿部的顺序强调各类关节

   文本：“颈关节对应头部，肩关节和肘关节对应大小臂，髋关节和膝关节对应大小腿”


4. **安装活动关节**

   画面：先为替换后的手臂安装肩关节，明确展示“先点手臂、再点躯干”的顺序；随后依次为另一只手臂、头部和两条腿安装肩关节、颈关节和髋关节

   文本：“先右键活动体块（如大臂），再右键固定体块（如身体），即可安装关节”

5. **强调安装条件**

   画面：特写两个直接相连的独立部件，在连接处高亮关节

   文本：“关节只能安装在直接相连的两体块之间”

6. **展示安装效果**

   画面：将安装好关节的成品装箱并放出，依次展示转头、手臂挥击和双腿行走，与本章开头的跳跃动作形成对比


7. **说明基础属性**

   画面：依次高亮全身、替换后的手臂和腿部，配合生命、伤害和移速图标；最后将成品装箱，展示按住 Alt 查看基础数值的提示

   文本一：“成品拟态生物的基础属性会随对应部位的体积等因素改变”

   文本二：“如整体体积越大，生命值越高；手臂体积越大，伤害越高；腿部长度越长，移速越快”


## 第四章：特性介绍

目标：让玩家理解特性如何随组织继承、按装配条件生效，以及如何检查和调整；轰炸机用于串联举例

1. **认识仿生特性**

   画面：展示苦力怕躯干与幻翼翅膀组成的成品，先展示振翅飞行，再用另一只成品展示接敌自爆；随后将示例定格，标出“自爆”和“扑翼飞行”

   文本一：“除了改变外形和基础数值，保留的供体组织还能赋予成品独特的仿生特性”

   文本二：“例如，组合苦力怕的自爆与幻翼的扑翼飞行，就能得到一架生物轰炸机”

2. **特性来自保留的组织**

   画面：将示例切换为台面上的部件，按来源分别高亮苦力怕组织与幻翼组织；再将幻翼的身体和翅膀分开高亮，用引线将翅膀与扑翼飞行条目相连

   文本一：“特性跟随保留下来的供体组织，混用不同来源的部件，可以组合它们提供的特性”

   文本二：“有些特性来自供体的各种组织，有些只由特定器官提供，例如飞行所需的翅膀”

3. **装配位置决定生效部位**

   画面：以不同颜色标出示例的全身、躯干、颈关节头部与两条肩关节翼臂，旁侧补充腿部示意；将自爆条目指向躯干，将扑翼飞行条目指向安装肩关节的翅膀

   文本一：“特性有各自的生效部位，有些作用于全身，有些只在头部、躯干、手臂或腿部生效”

   文本二：“关节决定头部与肢体的装配范围。对应组织要装在合适的部位，例如用肩关节将翅膀识别为翼臂”

4. **组织占比影响特性生效**

   画面：高亮示例的躯干范围，用不同颜色显示苦力怕组织与其他组织；改变两者比例，配合占比条展示自爆条目由灰色转为生效；旁侧用简图分别表示“保留即可”“达到门槛”和“按贡献改变效果”

   文本一：“有些特性只需保留对应组织，有些需要组织占比达到门槛，还有些会随组织贡献改变效果”

   文本二：“占比按特性的生效范围计算，例如自爆看躯干，翼部特性分别检查各条翼臂，不能只看全身用了多少供体组织”

5. **检查关节与配套条件**

   画面：依次对照缺少肩关节、只有一条有效翼、身体过重和条件满足的示例；每次只改变一项条件，在飞行条目旁显示对应的缺失原因，最后恢复为可飞行的成品

   文本一：“部分特性还需要对应关节、成套器官或其他配套组织，保留供体组织后也要检查这些条件”

   文本二：“例如，扑翼飞行需要足够的有效翼，并满足承重条件；组装时要同时考虑组织与身体结构”

6. **性情与智力来自头部**

   画面：高亮示例通过颈关节安装的头部，将纸箱属性中的“性情”和“智力”两项引到头部；旁侧分别用选敌与战斗动作图示说明它们影响的行为

   文本一：“性情与智力也是供体头部带来的特性，分别影响选敌方式和战斗策略”

   文本二：“保留符合条件的供体头部，才能参与性情与智力判定；更换头部时，也要考虑这些行为变化”

7. **组合特性并考虑取舍**

   画面：再次展示示例的自爆与扑翼飞行条目共同生效；随后在旁侧用独立的特性条目示意火焰免疫覆盖阳光灼烧，以及其他供体可能携带的不利特性，不将这些条目算入轰炸机

   文本一：“不同供体的特性可以共同作用，部分特性也会覆盖其他特性，最终效果取决于整具身体的装配结果”

   文本二：“供体还可能带来阳光灼烧、遇水受伤等不利特性，选择组织时要一起考虑”

8. **检查成品并继续调整**

   画面：将示例装箱，按住 Alt 展开特性列表，突出各部位分组与灰色条目的缺失原因；随后放回台面调整一处未满足的条件，再装箱展示该条目生效

   文本一：“装箱后按住 Alt，可以查看成品的特性与缺失条件；灰色条目表示这项特性尚未生效”

   文本二：“根据提示调整组织、装配位置与关节，再检查结果，逐步得到需要的特性组合”

9. **查阅具体规则**

   画面：展示手术指南在 JEI 中的用途，打开特性说明，依次强调效果、条件和供体列表；再示意从供体预览、刷怪蛋或装有生物的纸箱反查特性，最后回到完成的示例

   文本一：“在 JEI 中查看手术指南的用途，可以查阅各项特性的效果、生效条件和供体”

   文本二：“也可以从供体预览、刷怪蛋或装有生物的纸箱反查特性，按想要的能力规划下一次组装”

## 第五章：全工具介绍

目标：让玩家理解各工具在拆解、定位、连接、组合与收尾中的作用，具体按键与当前步骤由操作提示补充

1. **切换工具与查看提示**

   画面：展示普通手术盒的完整轮盘，依次扫过八种工具；选中一种工具后对准台面部件，突出工具名称、目标高亮和当前可用操作

   文本一：“手持手术盒，长按工具切换键，将光标移向所需工具后松开。默认按键为 Alt”

   文本二：“手术盒集成了常用手术工具，对应的独立工具或材料也能使用；瞄准目标时，屏幕会提示当前可以进行的操作”

2. **剪刀：剪开连接与拆卸关节**

   画面：依次展示剪开原有接缝、剪开后加胶缝，以及一次拆下多处相连的部件；再演示解除蜂蜜组合、整体取下组合和命中关节后拆卸回收，保留每种操作的目标高亮

   文本一：“剪刀用于拆解，可以剪开原有接缝或后加的粘合连接，也可以解除蜂蜜组合，或将组合整体取下”

   文本二：“直接命中活动关节时，会优先拆下关节并回收物品。操作前可以通过高亮确认拆解范围”

3. **铲子：清理多余部件**

   画面：在台面边缘放置废弃的连通部件，展示铲除后掉落黏液球；随后选中一块台面，展示清理与该台面相交的全部部件，对照两种清理范围

   文本：“铲子用于清理多余组织，可以铲除一个完整连通部分，也可以清理某块台面上的部件，并回收一些黏液球”

4. **强力胶与智能强力胶：连接部件**

   画面：在两个独立部件上依次标出粘合位置，展示移动、对齐与接触；再换用智能强力胶，演示确认前平移和旋转预览，最后完成连接

   文本一：“强力胶将两个部件的选中位置对齐并连接，确认时需要实际接触，并留有足够的台面空间”

   文本二：“手术盒使用智能强力胶，可以在确认前微调位置与倾角，适合组装需要精确对齐的部件”

5. **扳手：调整位置与姿态**

   画面：先高亮并调整一个体块，再切换为整个连通部分，展示平移、旋转和整体摆正；预览后分别演示一次确认与一次取消，在关节连接处保留高亮

   文本一：“扳手用于调整部件的位置和姿态，可以调整单个体块，也可以带动整个连通部分，或将整体摆正”

   文本二：“调整先以预览显示，右击确认，左键取消；确认时会检查空间与连接，已有的关节连接需要保留”

6. **蜂蜜瓶：固化刚性组合**

   画面：用几个相连体块组成一段肢体，使用蜂蜜瓶后以同一颜色高亮整个组合；将它整体搬动，再与另一段肢体通过关节连接，强调两段组合之间的活动边界

   文本一：“蜂蜜瓶可以把整个连通部分固化成一个刚性组合，方便把多个体块作为一段躯干或肢体使用”

   文本二：“固化后的组合会被视为一个完整部件；需要通过关节相对活动的两部分，应分别保留为独立组合”

7. **黏液球：补上原位胶缝**

   画面：展示两个已经贴合、但没有直接连接的体块；用黏液球依次选中它们，显示新增胶缝，前后叠影保持位置一致

   文本：“两个体块已经实际贴合时，可以用黏液球补上一条胶缝，保留它们当前的位置并建立直接连接”

8. **对称之杖：对称摆放现有部件**

   画面：展示一侧已经粘好的肢体和另一份待安装部件；依次选中待移动部件、参考部件与中心面，用半透明预览显示对称位置，确认后将现有部件移到另一侧

   文本一：“对称之杖参照已有粘合关系与所选中心面，对称复现部件的位置和倾角”

   文本二：“它会移动并粘合另一份现成部件，制作对称身体时需要提前准备好两侧材料”

9. **临时纸箱：搬动连通部分**

   画面：用临时纸箱选中一个完整连通部分，在同一台面换位，再展示搬到另一块工作面；放置预览中切换落地面，突出移动前后的整体结构一致

   文本：“临时纸箱用于整体换位或搬到另一块手术台，摆放时可以选择落地面，适合整理台面与调整装配布局”

10. **关节：指定活动部位**

    画面：展示另外准备的关节物品与类型轮盘，将五种类型分别指向头、上臂、前臂、大腿和小腿；在两段直接相连的独立部件上标出“先选活动部件、再选固定部件”，安装后展示相应动作

    文本一：“关节需要另外准备，颈、肩、肘、髋、膝关节分别对应头部、上臂、前臂、大腿和小腿”

    文本二：“先选择活动部件，再选择固定部件，让独立而直接相连的两部分获得相应的活动功能”

11. **空纸箱：装箱与释放成品**

    画面：用独立的空纸箱装起完成的身体，台面上保留未连接的零件；展开 Alt 属性后潜行右击释放，再捕获并放回台面，串联检查、使用与继续改装的过程

    文本一：“空纸箱用于收起命中的整个连通部分，完成成品包装；未连接的零件会留在台面上”

    文本二：“装箱后可以检查数值与特性，潜行右击释放；需要继续改装时，再将成品放回手术台”

12. **材料与耐久**

    画面：并列展示剪切、粘合与蜂蜜固化的工具图标，随后突出关节安装时数量减少、拆卸时回收的过程，角落补充“以服务器设置为准”

    文本：“通常情况下，剪切、粘合与蜂蜜固化不消耗材料或手术盒耐久；安装关节会消耗关节物品，拆下后可以回收”

13. **创造手术盒：改变拟态状态与附身**

    画面：切换到创造手术盒轮盘，依次展示拟态转化器将普通生物转化、拟态复原剂恢复生物，以及拟态附身器对缠魂后的生物进行附身与脱离

    文本一：“创造手术盒提供另一组工具，拟态转化器与拟态复原剂可以切换生物的拟态状态”

    文本二：“拟态附身器可以附身或切换到缠魂后的生物，附身后潜行右击可以脱离身体”

14. **部件复制工具：复用现有结构**

    画面：在创造手术盒中选择部件复制工具，高亮并复制台面上的完整连通结构，再在旁边放置副本，始终保留原件用于对照

    文本：“创造手术盒中的部件复制工具可以复制整个连通部分，保留原件并放置副本，方便复用已经完成的结构”
