# 仿生生物特性总表

本文按当前工作区代码与数据整理（Minecraft 1.21.1 / NeoForge），覆盖三类特性：

| 类别 | 枚举 / 解析器 | 数据目录 | 判定方式 |
| --- | --- | --- | --- |
| 全体块体质 | `BionicBodyTrait` / `BionicBodyTraitRegistry` | `data/create_biotech/bionic_body_traits/` | 以全身为范围，按保留体块**体积**计算覆盖率，不看具体器官 |
| 头部 / 呼吸 | `BionicHeadTrait` / `BionicHeadTraitRegistry` | `data/create_biotech/bionic_head_traits/` | 以头部（呼吸类为鳃 + 头部）为范围，**局部覆盖率** ≥ 门槛 |
| 特殊器官 | `BionicOrganTrait` / `BionicOrganTraitRegistry` | `data/create_biotech/bionic_organ_traits/` | 以该特性的器官部位为范围，**局部覆盖率** ≥ 门槛，部分还要求落地腿与负载 |

效果执行集中在 [SlimeBionicEntity.java](../src/main/java/com/nobodiiiii/createbiotech/entity/SlimeBionicEntity.java)，细雪行走另见 [PowderSnowBionicFootMixin.java](../src/main/java/com/nobodiiiii/createbiotech/mixin/PowderSnowBionicFootMixin.java)。

## 一、通用规则

### 1. 供体判定优先级

每项特性对供体物种的判定顺序为 **自动探测 < 实体标签（`#tag`）< 单个实体 ID**，`false` 可撤销低优先级结果。JSON 中 `automatic_detection: false` 时只看 `values`。

### 2. 体块体积

- 所有覆盖率都按体块**体积**加权。体积取捕获时每个模型体块的实际尺寸（方块³）；不足 1 像素的边按 1 像素计，因此平面的翅、鳍也有体积。
- 旧存档没有记录体块体积。成品中只要有一个来源缺少体积，整个成品就退回按体块数量加权。

### 3. 全体块覆盖率

```
覆盖率(特性) = Σ(具备该特性的物种所保留的体块体积) / Σ(全部保留体块的体积)
```

- 以全身为范围，与器官角色无关。
- 数值项（天然护甲、抗击退、自然恢复）同样按体积加权平均。
- 免疫效果取**所有**供体免疫集合的**交集**；只要混入一个不免疫的供体就失效。

### 4. 头部 / 器官局部覆盖率

头部和器官特性使用同一种覆盖率，只是范围缩小到一个部位：

```
局部覆盖率(特性) = Σ(部位内、具备该特性的物种的载体体块体积) / Σ(部位内全部保留体块的体积)
```

- **部位（分母）**：成品中带有该部位角色的全部保留体块。头部特性的部位是所有头部体块；鳃式水下呼吸和离水窒息的部位是鳃 + 头部；器官特性的部位是该特性各角色的并集（例如游泳专长为鳍 + 尾 + 触手 + 腿）；扑翼飞行的左翅、右翅各算一个部位，两侧都要达标。
- **载体（分子）**：具备该特性的物种的载体体块。优先使用该特性 JSON 的 `carriers`（模型部件名或 `#体块ID`）；该特性未声明此物种时，使用此物种已知的同角色体块（任一特性 JSON 的载体声明、解剖快照或 `bionic_anatomy/` 模板）。头部角色总会包含捕获时识别出的头部体块（与 Create 列车帽的头部判定相同）。
- 分母独立于特性匹配结果：没有该特性的供体，其同类器官仍计入局部覆盖率分母；没有任何该特性的普通组织仍计入全体块覆盖率分母。
- 常见的头、腿/足、翼、鳍、尾、触手、壳、刺、口器和攻击手会按捕获时保存的模型部件名识别；`body` 等含义不唯一的名称仍由实体专用载体声明或 `bionic_anatomy/` 模板确定。
- 不区分体块来自哪个供体，也不检查是否与成品其余部分相连。
- 默认门槛 `min_coverage = 0.5`（≥ 50% 即生效）。
- 示例：鲑鱼头、海豚头、村民头拼成一个头部时，鳃式水下呼吸的覆盖率 = 鲑鱼头体积 / 三个头的总体积，≥ 50% 即可水下呼吸。
- 器官特性生效后，会记录具体由哪些体块提供（`members`）。攻击类特性只在**这些体块所在的攻击臂**命中时触发。

### 5. 需要腿的器官特性

灵巧落地、减轻摔落、细雪行走、熔岩行走、攀墙额外要求：

- `有效腿数 = min(成品落地腿数, 载体体块数) ≥ min_legs`（灵巧落地、攀墙默认 2，其余默认 1）。
- `身体体积 ≤ 有效腿数 × max_body_volume_per_leg`（默认 16）。

### 6. 未生效原因（Tooltip）

| 原因键 | 显示文本 | 触发情形 |
| --- | --- | --- |
| `insufficient_coverage` | 所在部位占比不足 | 载体体块在场，但局部覆盖率低于门槛（扑翼飞行为任一侧翅膀不足） |
| `body_measurement_unavailable` | 身体测量结果暂不可用 | 腿类特性覆盖率足够，但成品还没有身体尺寸数据 |
| `purpose_mismatch` | 装配用途或负载不符 | 覆盖率足够，但落地腿数或负载不满足 |
| `no_ranged_attack` | 成品没有远程攻击路径 | 附效远程攻击（目前恒不生效） |

载体体块已全部切除，或该物种的载体无法识别时，不显示原因。

## 三、头部 / 呼吸特性（`bionic_head_traits`）

默认门槛 `min_coverage = 0.5`。部位为成品的全部头部体块；鳃式水下呼吸与离水窒息的部位为鳃 + 头部。载体读取 `GILL`（呼吸类）或 `HEAD`（其余）角色；呼吸类物种没有鳃的映射时，以整个头部为载体。

| 特性 ID | 中文名 | 适配器官（载体部件） | 对应生物（来源） | 生效条件 | 效果 |
| --- | --- | --- | --- | --- | --- |
| `water_breathing` | 鳃式水下呼吸 | 鳃 `GILL`：鳕鱼、鲑鱼为 `head`；热带鱼、河豚、鱿鱼、发光鱿鱼、蝌蚪为 `body`；美西螈为 `topGills` / `leftGills` / `rightGills` / `head`；守卫者、远古守卫者、海龟为 `head` | 自动：属于 `can_breathe_under_water`、非亡灵、非盔甲架、且不会在水中溺水，即美西螈、青蛙、守卫者、远古守卫者、海龟、鱿鱼、发光鱿鱼、鳕鱼、鲑鱼、河豚、热带鱼、蝌蚪（青蛙无鳃声明，以整个头部为载体） | 鳃 + 头部局部覆盖率 ≥ 0.5 | 在水中不会溺水 |
| `dry_suffocation` | 离水窒息（负面） | 鳃 `GILL`：鳕鱼、鲑鱼为 `head`；其余为 `body` | 数据：鳕鱼、鲑鱼、热带鱼、河豚、鱿鱼、发光鱿鱼、蝌蚪 | 鳃 + 头部局部覆盖率 ≥ 0.5；**且**无需呼吸覆盖率 < 0.5。头部以空气呼吸头为主时覆盖率自然不足 | 离水 300 tick 后每秒受 1 点干涸伤害；回到水或气泡中重置 |

| `tameable` | 可驯服 | 头 `HEAD`：`head`、`head_cube` | 自动：`TamableAnimal`（狼、猫、鹦鹉）或 `AbstractHorse`（马、驴、骡、羊驼、行商羊驼；排除骷髅马、僵尸马、骆驼） | 头部局部覆盖率 ≥ 0.5 | 无主人时喂史莱姆球即驯服；主人空手右键切换坐下；距离超过 10 格时跟随；协助主人攻击。失去该特性时清除主人 |
