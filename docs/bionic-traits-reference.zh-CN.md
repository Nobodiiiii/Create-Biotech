# 仿生生物特性规则与游戏内描述

更新日期：2026-11-13。适用版本：Create: Biotech 2.0.0-beta.2，Minecraft 1.21.1、NeoForge 21.1.234、Create 6.0.10-281。共 66 项特性。

## 一、通用规则

### 装配范围与覆盖率

载体是供体提供特性的组织，生效部位由关节装配位置决定。组合体按保留载体汇总特性，手术台、纸箱和实体共用装配判定。

| 生效部位 | 判定范围                                   |
| -------- | ------------------------------------------ |
| 全身     | 全部保留体块                               |
| 躯干     | 归入躯干的保留体块                         |
| 头       | 颈关节安装的头部；未安装头部时采用整个躯干 |
| 臂       | 每条肩关节及其肘关节链                     |
| 腿       | 每条髋关节及其膝关节链                     |

覆盖率 = 匹配供体载体的体积 ÷ 对应范围的保留体块总体积。体积按捕获体块的实际尺寸逐块相加，各边至少按 1 像素计。头、臂、腿分别按独立肢体链计算。

### 继承类型

| 类型   | 生效规则                                                         |
| ------ | ---------------------------------------------------------------- |
| 存在型 | 对应部位保留匹配载体，并满足配套要求                             |
| 门槛型 | 对应部位覆盖率达到门槛，默认 50%                                 |
| 比例型 | 匹配载体贡献效果，强度按占比或数值汇总                           |
| 特殊型 | 性情、智力按供体原始头部保留比例判定，默认至少 50%；同源碎片合并 |

性情与智力的 JEI 页面分别显示生效条件，头部保留比例读取各自的 `min_coverage` 服务端配置，并按百分比展示；登录与 `/reload` 后更新。

腿部特性默认需要至少一条达标腿链。扑翼飞行与扑翼缓降默认需要两条达标翼臂，扑翼飞行另需满足承重条件。飞行速度随有效飞行组织占全身体积的比例提高，额外组织的速度收益递减。

天然护甲、击退抗性、自然恢复、近战击退、体质按原供体体积分配：每个体块的贡献 = 供体数值 × 该体块捕获体积 ÷ 原供体全部体块捕获体积之和。力量单独按每条原生手臂分配：体块贡献 = 供体力量 × 该体块捕获体积 ÷ 其所属原生手臂的完整捕获体积；躯干、腿等组织不携带力量。装配后，只把生效范围内各体块的贡献直接相加；同一肢体内按唯一体块计数。供体数值和体块分配保留完整精度；最终全身、躯干或每条肢体的汇总值绝对值不足 0.1 时直接归零，不显示也不生效，其余四舍五入到小数点后 1 位，同时用于显示与实际效果。

分母固定为原供体完整体积，包含已经切除的体块；切割、拆装、拼入无修正组织都不会重分配已有体块的贡献。原供体完整体积来自捕获时保留的全部体块体积数组，切割和保存后仍保留；缺少该测量的旧组织不猜测数值。`min_coverage` 不再作用于数值型特性；其他继承类型继续沿用覆盖率规则。

体质（`health_offset`）与力量（`damage_offset`）支持正负贡献。体质覆盖全身；力量与近战击退对每条肩／肘关节臂链独立求和，仅作用于该臂近战。力量的供体数值表示每一条完整原生手臂的修正，例如末影人每条完整手臂均为 +3，半条为 +1.5；左右臂不互相平摊，也不分配给全身。力量默认值见[最终修正总表](vanilla-stat-offset-survey.zh-CN.md)；[完整双臂的空手近战 DPS 测算](vanilla-stat-offset-survey-archive-2026-11-13.zh-CN.md#原生双臂近战-dps-校准)与候选方案仅作为归档参考，不要求最终 DPS 与原版相同。原生手臂由捕获时的模型标签与原始连接识别，切割不会改变分母；缺少手臂测量时不猜测力量。多个供体或多条原生手臂的贡献可相加，同一原生手臂碎片合并只恢复该臂的原有总额。最终生命限制为 1 至配置上限（默认 400），最终单次伤害最低为 0，最终击退抗性仍限制为 0～1。

拟态生物的基础击退抗性为 0，最终击退抗性完全由躯干组织继承的击退抗性特性赋予，范围为 0～1（0%～100%）。

组合特性的支撑身体是共享配套，可支持同种供体的多个产出部件。可挤奶的乳房在牛与哞菇之间通用，身体类型决定可获取的产物。

### 特性覆盖

生效的覆盖方替代下列特性：

| 覆盖方             | 被替代特性         |
| ------------------ | ------------------ |
| 火焰免疫           | 火焰抗性、阳光灼烧 |
| 冻结免疫           | 冻结抗性           |
| 无需呼吸           | 水下呼吸、离水窒息 |
| 扑翼飞行、悬浮飞行 | 扑翼缓降           |
| 可驯服（宠物）     | 可驯服（家畜）     |

### 展示与交互

性情、智力独立显示；其余特性按全身、头部、躯干、手臂、腿部分组。体质固定排在全身组首位，力量固定排在手臂组首位。灰色条目附带待满足的条件，效果、目标与子特性在对应条目中列出。

JEI 的六项数值特性（体质、力量、天然护甲、击退抗性、自然恢复、近战击退）不显示“生效条件”字段。手臂部位图标的悬浮提示在部位名称下补充“特性只对对应手臂起效”。

史莱姆球用于驯服，成功率取有效驯服组织在头部范围的占比。已驯服生物可用瓶装或桶装活性史莱姆治疗。可骑乘背部按鞍位提供座位，骆驼背部每鞍提供前后双座；潜行右键或骑乘时按 E 打开装备界面。
